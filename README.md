# dreamy-vscode-neovim-config

I don't recommend anyone try to install and use this config as is, it is probably more useful as inspiration for your own, or if you just want to see my config.

This contains my nvim config files for use with vscode-neovim. I keep regular nvim and VSCode neovim configs and plugins separate via the vscode-neovim setting `Vscode-neovim: NVIM_APPNAME`. If you set it to "vscode-neovim", then that will be the name of the directory that will store the configs under `~/.config`. It will have other similar effects as well, look up what the setting does.
